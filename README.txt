NOTRE UNIVERS — VERSION AMÉLIORÉE

1. Décompressez le dossier.
2. Ouvrez index.html dans un navigateur ou envoyez l'ensemble du dossier sur GitHub Pages.
3. Conservez l'arborescence : css/style.css et js/script.js doivent rester dans leurs dossiers.

Pages incluses : Accueil, Notre histoire, Souvenirs, Jeux, Lettre, Surprise.
Jeux : quiz avec score et correction, memory avec compteur de coups/temps et redémarrage, labyrinthe jouable au clavier ou aux boutons.

PERSONNALISATION :
- Modifiez les textes des pages HTML pour remplacer les exemples par votre histoire réelle.
- Sur souvenirs.html, remplacez les blocs .memory-art par des balises img, par exemple : <div class="memory-art"><img src="images/votre-photo.jpg" alt="Notre souvenir" style="width:100%;height:100%;object-fit:cover"></div>
- Pour utiliser une vraie photo sur l'accueil, remplacez le contenu de .photo-placeholder par une image.
- Les polices sont chargées depuis Google Fonts ; les autres fonctionnalités sont en HTML/CSS/JavaScript natifs.
